# insight_collector

Alpha. Reads a Flutter VM Service and writes an Insight session.

An app depends on `insight`, not on this package. `insight_cli` and the DevTools panel use it. The session file, the frame grouping, and the side-by-side rows are defined here.

Suggestions and new features go to [the issues page](https://github.com/ylahav/insight/issues).
